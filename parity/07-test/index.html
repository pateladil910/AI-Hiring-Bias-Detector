Optimized LRU Cache Eviction Policy

Implement a Least Recently Used (LRU) Cache structure supporting get(key) and put(key, value) in O(1) time complexity.

Input Constraints:

  • capacity > 0
  • Keys and values are positive integers
  • Maximum 10^5 operations per test execution

Example:

LRUCache cache = new LRUCache(2);
cache.put(1, 1);
cache.put(2, 2);
cache.get(1);       // returns 1
cache.put(3, 3);    // evicts key 2
cache.get(2);       // returns -1 (not found)
